# Calculadora Digital Ionic

Aplicativo feito com Ionic Angular. A interface usa fundo branco, cabeçalho azul piscina e teclas em grade responsiva.

## Requisitos
- Node.js LTS (20 ou superior)
- npm

## Como iniciar
1. Extraia o ZIP para uma pasta.
2. Abra um terminal nessa pasta (a que contém `package.json`).
3. Instale as dependências do projeto: `npm install`.
4. Inicie o aplicativo: `npm start`.
5. Abra no navegador o endereço exibido no terminal (normalmente `http://localhost:4200`).

Para gerar os arquivos de produção: `npm run build`. O resultado fica em `www/`.

## Teclas
Toque nos números e operadores. `=` calcula; `AC` limpa; `⌫` apaga o último caractere; `.` adiciona decimais. Também aceita teclado físico.
